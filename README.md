# ⚡ ThunderX: Workflow File Organizer

**ThunderX** is a lightning-fast, lightweight Python automation tool designed to optimize your workspace and instantly clean up your cluttered Windows `Downloads` folder.

## 🚀 How It Works
When you run ThunderX, it automatically scans your default system `Downloads` folder and beautifully sorts your messy files into organized categories based on their extensions:
* 📷 **Images** (`.jpg`, `.png`, `.gif`, `.webp`)
* 📄 **Documents** (`.pdf`, `.docx`, `.xlsx`, `.txt`)
* ⚙️ **Applications** (`.exe`, `.msi`)
* 📦 **Archives** (`.zip`, `.rar`, `.7z`)

## 🛠️ How to Use It On Your Computer

1. **Clone this repository** or download the `main.py` file.
2. Open your command line or terminal inside the folder.
3. Run the script by typing:
   ```bash
   python main.py
   ```
4. Open your `Downloads` folder and watch your files get automatically organized!

## 📝 Requirements
* Windows OS
* Python 3.x installed
